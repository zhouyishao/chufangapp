# 家里有菜：首页交互原型

启动：

```bash
python3 -m http.server 4173 -d docs/prototypes/home-feed-interactive
```

访问 `http://127.0.0.1:4173/`。

锁定项：Banner 393×420；搜索框和铃铛独立；频道顺序固定；Banner 后第一模块为时令果蔬；底部导航为首页、分类、菜篮、我的。

当前已实现：

- 家常精选、挑选指南、今晚值得做、清爽一餐、食材变菜谱、饮品搭配、本周热门。
- 搜索、频道、收藏、换一批、卡片和底部导航反馈。
- 推荐流加载、错误重试和结束状态；使用 `?simulateError=1` 验证错误态。
- 字体 100%、120%、150%、200% 调试；使用 `?debug=1` 显示切换按钮。
- 图片固定比例、延迟加载和加载失败占位。
- 底部“分类”进入统一分类页：顶部五个大类、左侧二级分类、菜谱单排、食材/水果/饮品/调料双列。
- 分类页菜篮图标支持“未加入（线性＋加号）/已加入（绿色面性＋白色对勾）”两种状态，点击后显示反馈。

验证：

```bash
cd docs/prototypes/home-feed-interactive
node verify.mjs
node --check app.js
```
