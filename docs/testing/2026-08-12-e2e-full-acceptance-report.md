## 1. 测试目标

验证 MVP 的三条核心链路：

1. 管理员在后台配置内容，后端真实保存，C 端正确展示。
2. C 端用户登录并产生收藏、浏览、搜索、菜篮、家庭、投稿等数据，后台能正确查看。
3. C 端、管理后台的所有可达菜单与主要交互不存在阻断性错误，并具备基本的加载、空态、错误提示、校验和权限保护。

## 2. 执行原则与问题分级

- 全部 UI 操作使用内置浏览器执行；不以接口直调替代 UI 验收。
- 写入型用例使用带 `E2E-20260812` 前缀的可识别数据；删除只针对本轮新建数据，避免破坏既有数据。
- 每个失败项至少稳定复现一次，并记录页面、操作、实际结果、期望结果与跨层定位证据。
- P0 阻断：系统不可启动、无法登录、核心链路整体不可用、数据破坏或严重安全问题。
- P1 严重：核心功能不可完成、后台配置无法到达 C 端、用户数据无法到达后台。
- P2 一般：局部功能、校验、分页、筛选、跳转、状态同步或异常兜底不正确。
- P3 建议：文案、体验、一致性、轻微视觉或非核心能力问题。
