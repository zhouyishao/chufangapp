# 家庭管理两级流程设计

## 目标

修正“家庭切换、家庭列表、成员权限管理”混在同一页面的问题，让用户先选择要管理的家庭，再进入该家庭的成员管理。

本设计只修改 `docs/prototypes/home-feed-interactive/` 中的交互原型，不修改正式 C 端、接口或数据库。

## 信息架构

```text
我的
├── 周家 ▼                  快速切换当前家庭
├── 管理                    进入家庭管理页
├── 口味                    进入当前家庭口味页
└── 家庭码                  展示当前家庭二维码

家庭管理
├── 周家                    点击进入周家成员管理
├── 爸妈家                  点击进入爸妈家成员管理
├── 奶奶家                  点击进入奶奶家成员管理
├── 创建家庭
└── 扫一扫加入家庭

家庭成员管理
├── 家庭概览
├── 成员列表
├── 成员备注
├── 角色与权限
├── 邀请成员 / 家庭码
└── 家庭设置
```

## 页面一：我的页面家庭模块

- “家庭名称 + 下拉箭头”只用于切换当前家庭。
- 下拉菜单显示家庭名称、成员数、待采购数和当前选中状态。
- “管理”快捷入口进入家庭管理页。
- “口味”进入当前家庭的偏好页面。
- “家庭码”进入当前家庭的二维码页面。
- 不在我的页面直接展示成员删除、授权或备注操作。

## 页面二：家庭管理

### 页面职责

只负责展示用户所在的所有家庭，并提供创建或加入家庭的入口。

页面顶部导航已经显示“家庭管理”，内容区直接进入家庭列表。禁止增加“家庭 / 管理我的家庭 / 切换家庭……”这类绿色引导词、大标题和说明段落。

### 家庭列表行

每个家庭显示：

- 家庭名称。
- 成员数量。
- 当前用户在该家庭中的角色：创建者、管理员或成员。
- 当前家庭状态。
- 进入箭头。

点击整行进入对应家庭的成员管理页，不在列表行直接放成员权限按钮。

### 页面操作

- “创建家庭”：进入创建家庭流程。
- “扫一扫加入家庭”：调用扫码入口。
- 空状态：说明用户还没有家庭，并同时提供创建与扫码加入。

## 页面三：家庭成员管理

页面顶部导航显示当前家庭名称或“成员管理”，内容区直接显示紧凑家庭摘要与成员列表。禁止重复放置引导词、大标题和功能说明。

### 顶部信息

- 家庭名称。
- 成员数量。
- 当前用户角色。
- 家庭码入口。

以上信息使用一行或两行紧凑摘要，不做独立 Hero 或介绍模块。

### 成员行

每位成员显示：

- 头像。
- 姓名。
- 用户对该成员设置的备注。
- 创建者、管理员或成员角色。

点击成员行打开成员操作面板。成员列表不直接平铺多个操作按钮，避免页面拥挤。

### 成员操作面板

- 编辑备注。
- 设为管理员。
- 取消管理员。
- 移除成员。

危险操作使用明确的确认面板，说明影响后才能执行。

## 权限规则

| 操作 | 创建者 | 管理员 | 普通成员 |
|---|---:|---:|---:|
| 查看成员 | ✓ | ✓ | ✓ |
| 邀请成员 | ✓ | ✓ | — |
| 修改成员备注 | ✓ | ✓ | 仅自己的备注 |
| 设为 / 取消管理员 | ✓ | — | — |
| 移除普通成员 | ✓ | ✓ | — |
| 移除管理员 | ✓ | — | — |
| 退出家庭 | 转让创建者后 | ✓ | ✓ |
| 解散家庭 | ✓ | — | — |

补充约束：

- 创建者本人不能被移除。
- 创建者必须先转让创建者身份，才能退出家庭。
- 管理员不能移除创建者或其他管理员。
- 成员备注为当前用户自己的称呼，不覆盖对方真实昵称。

## 返回关系

- 家庭成员管理返回家庭管理页。
- 家庭管理页返回我的页面。
- 家庭码和家庭口味返回当前家庭上下文。
- 切换家庭后，我的页面、菜篮、家庭码、家庭口味和成员管理同步更新当前家庭。

## 原型交互状态

- 家庭下拉：关闭、展开、切换成功。
- 家庭列表：加载、正常、空、错误。
- 成员操作：默认、备注编辑、权限确认、移除确认。
- 创建或加入家庭：成功后自动切换为新家庭。
- 无权限操作不显示；不能只做禁用按钮。

## 验收标准

- 家庭管理页首先展示家庭，而不是成员权限。
- 家庭管理和成员管理内容区均不出现重复页面标题或介绍文案。
- 点击家庭整行进入该家庭成员管理。
- 家庭成员管理中能查看备注和角色。
- 创建者可设置管理员、取消管理员和移除成员。
- 所有危险操作都有二次确认。
- 家庭名称下拉只承担切换家庭。
- 返回层级正确，不直接从成员管理跳回我的页面。
- 393px 页面和 150%–200% 字体下无横向溢出或按钮截断。
