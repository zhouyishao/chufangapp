# 内容模块配置重构设计

## 目标

后台允许运营人员自由新增、删除、排序和配置模块，也允许维护各内容类型的分类；同时通过有限的 C 端展示模板和明确的数据规则，避免展示模板、内容类型和分类互相自动覆盖。

本版本不实现城市定位和地方特色推荐，只保留后续扩展位置。

## 核心原则

1. 模块自由，模板有限：模块可自由增删和排序，C 端构图只能选择已接入的展示模板。
2. 类型显式：展示模板不能自动修改内容类型。用户主动切换内容类型时，才确认清理不兼容的分类和已选内容。
3. 分类独立：菜谱、食材、水果、饮品和调料分别读取自己的分类库，分类可在分类管理中新增、编辑、上下架和排序。
4. 用途分离：普通内容推荐和分类入口是两种模块用途，分类入口展示分类记录，不把分类伪装成内容。
5. 所见即所得：保存前必须显示真实 C 端模板预览、匹配数量、缺图和内容不足提示。

## 配置流程

### 1. 展示位置

- 所属频道。
- 展示范围：频道首页或指定分类页。
- 模块排序。
- 启用状态与生效时间。

### 2. 模块信息

- 后台识别名称。
- C 端标题与副标题。
- 是否显示标题。
- 是否显示“查看更多”。

### 3. 模块用途与展示模板

模块用途：

- `CONTENT`：展示菜谱、食材、水果、饮品或调料。
- `CATEGORY_NAV`：展示对应内容类型下的分类入口。

展示模板是有限集合：横滑方图卡、双列方图卡、横向图文列表、单张重点推荐、紧凑列表、分类横滑卡、分类宫格和文字分类栏。

模板切换只改变构图，不修改内容类型。

### 4. 内容规则

内容模块支持：

- 手动选择内容。
- 按一个或多个分类自动获取。
- 按一个或多个标签自动获取。
- 分类与标签组合获取。

分类入口模块支持：

- 选择内容类型。
- 多选需要展示的分类。
- 手动调整分类顺序。
- 配置点击后进入的筛选列表。

排序方式包括手动排序、运营排序、最新发布、热门优先和随机轮换。

### 5. 核对与预览

- 真实 C 端构图。
- 匹配内容数量和实际内容。
- 内容不足、缺图、未发布提示。
- 点击目标和查看更多目标。

## 分类结构

分类管理与首页模块配置解耦。每种内容类型维护自己的分类，支持两级结构和自定义排序。本版本沿用现有内容分类、菜系和标签数据，不建设城市与地理位置模型。

菜谱可使用餐次、菜式、烹饪方式和场景等分类或标签；地方菜与定位推荐留到下一版本单独设计。

## 旧数据迁移

- 保留旧模块的标题、排序、状态和已选内容。
- 根据旧构图匹配新的展示模板。
- 根据旧模块真实内容类型读取对应分类。
- 不再使用展示模板推断或修改内容类型。
- 无法安全识别的旧模块标记为“需要确认”，禁止静默发布错误配置。
- 用户保存后写入新规则；不清库，不删除内容资产。

## 验收标准

- 菜谱模块不会因为模板切换显示食材分类。
- 菜谱、食材、水果、饮品和调料都能自由新增模块并选择各自分类。
- 分类入口和内容推荐的配置语义清晰。
- 切换内容类型必须显式确认，不发生隐式清空。
- 后台预览与真实 C 端模板一致。
- 旧模块可打开、确认并保存为新配置。
