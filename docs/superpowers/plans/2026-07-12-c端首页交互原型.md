# C 端首页交互原型 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个独立可运行的 393pt C 端首页高保真交互原型，验证已锁定 Banner、推荐流、Dynamic Type、吸顶频道和 Liquid Glass 底部导航。

**Architecture:** 在 `docs/prototypes/home-feed-interactive/` 创建无依赖静态原型。HTML 负责语义结构，CSS 负责 Token、适配与材料，JavaScript 只负责滚动状态、收藏、换一批、推荐反馈和加载状态；不连接现有前后端。

**Tech Stack:** Semantic HTML5、CSS custom properties、原生 JavaScript、Node.js 静态断言脚本。

## Global Constraints

- 不修改 `frontend/`、`server/`、`admin-frontend/`。
- iPhone 15 基准宽度固定 393pt；同时验证 375pt 和 360pt。
- Banner 固定 `X=0, Y=0, W=393pt, H=420pt`；未经用户明确要求不得修改。
- 搜索框与铃铛同一行，五频道位于搜索行下方；滚动后搜索隐藏、频道吸顶。
- Banner 下第一模块固定为“时令果蔬”。
- 字号：模块标题 22px/600，内容标题 17px/600，正文 16px/400，辅助信息 15px/400，紧凑名称 14px/500，底部导航 11px/500。
- 所有常用交互热区不小于 44×44px；支持 200% 字体缩放时的单列降级。
- Liquid Glass 只用于搜索、吸顶频道和底部导航，不用于内容卡片。
- 图标采用统一 24×24 视口和 SF Symbols 语义，不使用 emoji。

- [ ] **Step 3: 实现滚动和控件行为**

```js
function setScrolledState(scrolled) {
  document.documentElement.classList.toggle('is-scrolled', scrolled);
}
function toggleFavorite(button) {
  const selected = button.getAttribute('aria-pressed') === 'true';
  button.setAttribute('aria-pressed', String(!selected));
}
function rotateRecommendations() {
  document.querySelector('[data-refresh-feed]').classList.add('is-loading');
  window.setTimeout(() => document.querySelector('[data-refresh-feed]').classList.remove('is-loading'), 500);
}
function setFeedback(value) {
  document.querySelector('[data-feedback-status]').textContent = value === 'less' ? '已减少此类推荐' : '会继续优化推荐';
}
function appendFeedBatch() {
  document.querySelector('#feedSentinel').dataset.state = 'loaded';
}
```

- [ ] **Step 4: 使用 IntersectionObserver 实现分页触发**

```js
new IntersectionObserver(([entry]) => {
  if (entry.isIntersecting) appendFeedBatch();
}, { rootMargin: '240px' }).observe(document.querySelector('#feedSentinel'));
```
